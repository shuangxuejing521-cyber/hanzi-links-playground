# 字源图例与许可

核查日期：2026-11-05。

汉典当前[服务条款](https://zdic.net/terms/)第四节声明采用 CC0 1.0。本站按具体字页实际列出的字形，保留代表字例、文物/文献出处和原图库链接。数据见 `src/data/radical-evolution.json`；本地 SVG 位于 `public/images/evolution/`。

用户提供的[木字页面](https://zdic.net/hans/木)列出甲骨文、金文、楚系简帛、说文、秦系简牍、隶书及楷书。教学主界面筛选甲骨文、金文、《说文》小篆和楷书，避免把不同地区与并行书写材料误作固定先后。某栏缺图不等同于该字当时不存在。

《说文》字形为小篆资料的传录，不把文献编纂时代当作字形起源时代。木、水的秦系与隶书栏目可能选中同一字例，因此不人为重画差异；女的隶书栏目首例涉及泰山刻石，主教学序列不采用它证明隶变。

早先核查的26幅 Wikimedia Commons 公共领域古字形摹写保留为补充资料，出处和许可见 `src/data/ancient-forms.json`。释形论证仍交叉核对香港中文大学《汉语多功能字库》、教育部字典和中央研究院《汉字古今字资料库》，不同解释保留异说标记。

实物和动作照片为 AI 生成参考图；不作为文物照片或字源证据。完整提示词及图片清单见 `docs/image-prompts.json`。
