# 有出处的部件图解修订

用户发现旧版场景图重复且形状不对应。保留当前公开网站、26类、171组合及2500词搜索和本机进度；对全部152个可选部件和171组合核查意义、构形和图片。

采用可检验字形的方案：实物示意（仅有可靠象形依据的根部件）→本字笔画→偏旁笔画；每个组合以真实字形轮廓分别着色，显示左/右部角色。部件详情显示独立字义、在本字中的作用、来源、争议和简化关系。抽象/有争议的部件不强配实物；不能把声旁独立义硬解释为整字含义。

曾考虑仅替换彩色场景图，但这不能解决字形对应；全部使用生成图片又不能保证逐笔正确。因此用原创建模示意和开放许可的真实SVG笔画，保留现代释义图作为辅助，明确与字源分层。

现代字形依据CJKVI与MakeMeAHanzi；历史说明优先CUHK/MOE，无法确认的标注现代拆形或有争议。图示为教学重绘，不伪称古文字原件。使用现有React/TypeScript，无账户或付费依赖。原公开访问不变。
