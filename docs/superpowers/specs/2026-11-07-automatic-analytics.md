# 自动使用统计与创始人后台

2026-11-07用户最新决定覆盖此前研究编号方案：不发码、不要求学生注册或提供姓名/手机号/邮箱，后台自动统计即可。用户已明确“好的”，直接实施。本版不开发分组、前后测、教师发码或通用教学CMS。

保留同一公开Site和现有全部学生功能/图片/结构，增加浏览器随机代号、会话、偏旁实际曝光/主动点击、汉字/词语查看、材料使用、学习路径、有效活跃时间和逐次组字作答。浏览器代号不是实名学生或跨设备身份；清数据/换设备视为新访问者。旧本机进度不冒充集中历史统计。统计从上线开始，不追补历史。

创始人通过现有ChatGPT登录进入/admin，服务端ADMIN_USER_IDS白名单授权；当前账号已由Sites核实owner。上线初期白名单为空时全部拒绝，不允许首个登录者抢占；读取所有者实际登录身份后通过Sites服务端环境配置绑定。公开访客不能读统计、导出或编辑网站。用户的建站平台owner/source修改权限保留；本版只增加统计管理。

原React学生App作为客户端整体移入Sites Vinext全栈骨架，保留public资源路径及原CSS顺序。D1存访客摘要、会话和白名单事件；不写学生姓名、联系方式、原始IP、完整搜索词或设备指纹。自动统计有简短韩语说明、停止统计及清除此设备代号入口。匿名事件通过安全Cookie绑定服务端访客，客户端不可指定他人身份或提交任意事件内容。

后台中文界面支持7/30/90日与日期范围、HSK范围及模式筛选；总览、偏旁排行、每日趋势、字词热度、学习路径、练习表现、数据说明和CSV导出。点击率=点击过的会话/实际曝光会话；默认纟/红不是主动点击。首次作答与重试分开，未收录组合不是断言汉字错误，挂机时间不计。统计来源是已保存事件，空数据不造示例；访问代号不能称为学生人数，使用数据不宣称因果教学效果。

首版事件结构见src/analytics/contracts.ts；数据保留及身份限制在后台和导出字段说明中明确。原始事件与汇总可复核，事件ID幂等去重，参数化查询、请求白名单/大小上限/同源验证、会话内速率限制、限时有界重试。后台和导出均服务端鉴权。管理员操作排除于学生统计。
