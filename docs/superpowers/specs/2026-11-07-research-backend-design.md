## 方案比较与选择

| 方案 | 能做什么 | 取舍 |
| --- | --- | --- |
| 只记匿名访问 | 热门偏旁、会话内路径 | 不能可靠匹配同一学生的跨日测验，不能满足三个研究目标 |
| 教师研究编号＋同站研究后台 | 关联跨天记录、管理分组和测验、导出研究数据 | 需要服务端、数据库和后台权限；用户已选择这种学生识别方式 |
| 学生自行注册 | 同样可关联跨天记录 | 增加账号和个人资料负担，用户明确不需要 |

架构提议：保留现有学生界面，按 Sites 支持的 static→Worker 流程迁移到完整 Vinext 骨架，D1存结构化数据，R2仅存后台新上传的照片。原有静态图片和SVG保留原路径。沿用同一project_id和公开访问，不另建一个替代网站。此架构是实现者的建议，不是用户指定的技术栈。

## 学生编号与访问流程

1. 创始人在研究后台创建研究/班级，批量生成指定数量的编号，如30、50、100份。
2. 学生拿到一串不含个人信息的随机码，例如展示示例 `HZ-7K2Q-M9TR-K8CD`。这是示例，不是真实可用凭据。码不编码姓名、生日、班级或实验组。
3. 页面增加一个简短的韩语“연구 참여”入口。学生输入编号，阅读研究说明并选择是否参加；不参加仍可正常浏览学习。
4. 同一编号在另一天或另一设备使用，关联到同一个内部participant_id。研究会话使用服务端签发的安全Cookie；原始研究码不放URL、localStorage、公开日志或研究导出表。
5. 明显显示当前研究代号、同步状态、“退出此设备”和“退出研究”。退出设备只清会话，不删除历史；退出研究立即停止研究采集并撤销研究会话。数据删除另有明确确认流程。

教师自己保管“研究代号对应哪位学生”的名单，不上传本网站。研究编号是可关联的代号，不宣称这些纵向数据在所有情况下都完全匿名。

参与入口用简短韩语提醒不要交换编号，共用设备使用后退出；原有“记录保存在本机”的说明在研究模式下改为准确说明研究记录会同步到后台，普通非研究学习的本机记录逻辑保持原样。

编号实现约束：使用加密随机源及足够熵的不可猜测码，D1唯一约束；只保存带服务端密钥的码摘要。完整码仅在发放/下载时显示，研究分析使用另一个如P001的代号。遗失时由创始人重发，撤销旧码和旧会话，保留相同participant_id。研究码不能用于管理后台，也不能查询其他学生。

## 创始人权限与公开访问

- `/`及普通教学内容保持公开，访客无需登录。
- `/admin`及后台API只允许经过服务端授权的创始人账号。使用Sites现有ChatGPT登录；“已登录”不自动等于管理员。
- 创始人可管理研究、发码/停码、设置测验与组别、查看统计、导出数据、编辑允许修改的教学内容和照片。
- 初版只设一位创始人，不开放公共注册管理员、学生编辑或自助角色升级。以后添加协作者属于单独授权事项。
- 绑定创始人时，实际Site登录身份必须与当前已核实owner关联。初始化为“尚无管理员时全部拒绝”，不能采用第一个访问者/第一个登录者自动成为管理员。用服务端一次性初始化凭据与实际登录身份完成绑定，成功后禁用初始化；凭据不进代码、浏览器包或版本文件。实际绑定由已授权的网站所有者完成，不能只凭客户端传来的角色或邮箱。
- 创始人账号身份和研究学生数据分表；学生研究表不保存创始人的邮箱等资料。

## 后台功能范围

### 1. 总览与偏旁排行

日期、研究、班级、组别、HSK范围、学习模式筛选；展示参与人数、会话数、活跃时长、作答和完成情况。研究编号人数和匿名访客会话数分开显示，不能合并称“学生总人数”。无数据时显示真实空状态，不生成示例统计充当真实数据。

偏旁同时展示主动点击量、去重参与人数、可见会话数、点击率、回访数、该类可学字数。默认显示、等级切换造成的自动选中和学生主动选择分开。

### 2. 学习路径与材料使用

展示偏旁→汉字→词语→组字→测验的时间序列和转移汇总，以及古字形切换、轮廓开关、说明展开、发音使用、收藏/复习。把图片确实显示和用户点击分开；单纯渲染DOM不算认真学习。熊猫雨只作为娱乐交互单列，不计为字词学习成绩。

### 3. 练习与测验

练习保留原流程，逐次记录选择部件、目标、首次/重试、提示和结果。暂未收录的组合记为`uncollected`，不是断言不成字；游戏分数也不当作标准化测验。

增加独立研究测验，明确`pre / immediate_post / delayed_post / transfer`阶段。前后测材料与答案在研究激活时固定并版本化，服务端计分；测验不提供即时答案、组字提示或随意重试。记录未答、跳过、中断与已提交，不把缺测当0分。练习与测验的记录严格分开。

首版题型限于韩语词义四选一、拼音四选一、左右部件组合三种，教师按研究目的选择使用哪些题型，各题型分数分别导出。四选一仅按冻结选项ID精确判分；部件组合按冻结的实际部件/布局及正确答案判分。不扩展为作文、自由输入、手写识别或自动主观评分系统。此有限题型范围是实现者根据现有网站能力提出的默认方案。

建议默认延迟后测为7天，由教师在研究激活前修改；同时保存实际测试间隔。题目数、题库及合格条件由教师创建研究时设置，没有配置完整不能激活测验。优先选已有可靠图片和核对材料；不能把未完成教学材料的11,000词全部当成等价实验材料。

### 4. 研究和分组

支持观察性研究，以及常规文字学习组/网站完整方法组。研究创建默认草稿，普通教学网站不自动进入实验。研究说明、固定材料、测验和分组规则配置完成后，由创始人启动。

正式比较模式：实验条件由服务端按研究预先配置的规则分配并固定，保留分配单位、规则版本及时间。支持教师指定的班级分配，或按学生研究编号随机分配；后台需提示班级分组分析和学生分组分析不同。学生不能自行选择条件。整体方法的比较不宣称能单独证明图片/字源/游戏各自的效果。

研究任务在独立研究入口内执行；普通学生主页结构保持原样。两组使用固定的同一组目标材料与测验，并记录学习时长和练习机会。实施者负责可重现的题序随机化和交卷规则，教师在草稿预览中确认题目内容再激活。不能直接用现有固定从“油”开始的练习序列充当前后测。

公开完整版不会因实验而被关闭。已识别的对照组参与者若进入普通完整版，允许正常学习，但把图片/字源/组字的额外接触记录为跨条件材料暴露。主汇总保留原分配组，额外显示这些暴露和可供敏感性分析的标记，不静默转组或自动剔除。未输入编号、换设备或离站学习无法完整观测，因此“没有记录”不能解释为“从未接触”；参与说明和导出字典明确这一限制。这是实施者提出的默认处理方式。

### 5. 教学内容修改

创始人可修改教学用中韩释义、说明文案、已有图片的选用以及上传替换照片；提供草稿、预览、发布和版本记录。界面不提供任意HTML/脚本执行。新图片通过服务端鉴权、类型/大小检查后存R2，限制为常见图片格式。

原始官方词表编号、官方级别、字形笔画、来源审计记录保持规范数据层；后台编辑保存为带编辑者和时间的覆盖层，不悄悄改写官方词表。需要修订官方标准或字形来源时另做有出处的数据更新。

研究使用冻结的内容版本。发布新教学内容不改变已激活研究的题目和材料；旧引用照片/版本在被研究记录引用期间保留。创始人的平台所有者权限仍可用于后续源码修改，网站内编辑器不是任意源码IDE。

### 6. 导出与口径说明

提供UTF-8 CSV及Excel研究数据导出：参与者代号/组别表、会话表、操作事件表、逐题作答表、学生级汇总、字词/偏旁汇总，以及字段字典和计算规则版本。导出不含登录研究码、真实姓名、手机号、邮箱、原始IP或完整自由输入搜索词。表格单元格需防公式注入。

导出保存筛选条件、导出时间、数据截止时间、app/content/instrument版本、时区、事件去重与排除规则。允许缺失值，不替代成虚构成绩；原始记录可追溯到汇总。

## 统计口径（首版提议，作为instrument_v1固定）

| 指标 | 定义与限制 |
| --- | --- |
| 主动偏旁点击 | 用户点击/拖入/键盘选择的显式操作；初始自动展示与等级切换另记 |
| 偏旁点击率 | 至少点击过该偏旁的会话数÷实际可见该偏旁的会话数；可见暂定至少50%面积持续1秒，不声称证明注意 |
| 首次无提示正确率 | 同一参与者、题目、测次的首次无提示已提交正确数÷首次无提示已提交题数；另列未答和提示后作答 |
| 重试 | 同一trial_id内的后续提交，保留attempt_no；不覆盖首次答案、不重复加首次分 |
| 有效活跃时间 | 页面在前台且最近60秒有操作的时间；通过心跳累计并截断，不能把打开时长叫注意力时长 |
| 反应时间 | 题目/图片加载并可作答后，到首次提交的有效前台时间；中断/加载失败另标 |
| 学习增益 | 同一人不同测次的可比得分及变化；不只给一个未经解释的归一化提升百分比 |
| 延迟结果 | 延迟后测正确率与即时后测并列，记录实际间隔；缺席不是0分 |
| 迁移表现 | 未直接教学的新字任务，分意义/读音/部件任务；记录是否被之前浏览或搜索过 |
| 数据完整度 | 分配、同意参与、前测、学习、后测、延迟测验各阶段人数及缺失/退出情况 |

`learning_family_id`使用当前26类教学分类，`dictionary_radical_ids`可使用206类字典归部，`component_ids`为实际拆形。三者不能混成一个“部首ID”；一个词按多个部首归类时，各类计数可重叠，总词数去重另算。

## 数据结构与采集约束

核心表：`admin_memberships`、`studies`、`study_conditions`、`participants`、`research_code_digests`、`participant_sessions`、`content_revisions`、`assessment_versions`、`assessment_trials`、`events`、`export_audit`。具体字段类型和索引由实现者确定；不在请求处理期间建表，使用Sites/Drizzle受管迁移。

事件最少包含：唯一event_id、participant_id或短期匿名session_id、session_id、event_name、client_time、server_received_at、单调sequence、研究/班级/分配条件、学习模式、词库/HSK范围、教学偏旁/字/词/图片ID、动作来源、trial_id、attempt_no、提示状态、有效时间、app/content/instrument版本。测验得分由服务端按冻结答案重算，不接受客户端直接声明“答对”。

事件使用白名单和长度/类型校验；批量上传、唯一ID去重、重试幂等、研究编号会话授权、同源写入和频率限制。服务器忽略客户端指定的其他participant_id或分组。迟到/重复/乱序/离线记录有明确标志，不能无限信任客户端时间；正式测验需要在线提交。

普通访客可继续不参加研究。首版默认不为未同意研究的访客创建跨日追踪ID，也不把其本地进度上传；后台指标默认明确标注“研究参与者”。若以后启用一般访客匿名使用统计，需另设说明与选择，并仅用短期会话标识，不能当作已知学生数。

原始研究码、姓名、联系方式、完整自由搜索输入、原始IP、精确位置、设备指纹均不主动写入研究表。搜索事件只记已选词条ID、结果数量、是否无结果等受控字段。平台自身基础设施日志不冒充本应用能完全控制或消除。

## 保存、退出和可靠性

保存期限提议默认12个月，可由教师在研究草稿中调整，并在参与说明中展示明确截止日期；这是产品默认建议，不是法律或学校要求。到期停止新采集并提示创始人导出/处理，不自动不可逆销毁未导出的研究材料。退出研究立即停止采集；参与者数据删除和创始人永久删除操作需要明确二次确认。

退出后的首版默认规则：该参与者的历史记录也从通常统计和论文数据导出中排除，后台只展示退出/缺失人数。受限原始记录暂留供创始人处理退出与删除请求，不能在论文导出中静默重新纳入；删除确认后清除可关联的研究记录。已有导出文件不会被服务器远程改写，后台记录退出生效时间并提示重新导出。学生参与说明写明此规则；重新加入需要再次明确同意，不能仅由教师恢复编号。这是实现者为避免退出含义不清而提出的默认方案。

公开学习不得依赖统计服务成功；上传失败显示真实同步状态，保留有界重试队列，不让学生答题卡住。后台不能悄悄把本机队列未上传的事件算进已保存数据。安全Cookie退出、编号撤销与更换、共享设备切号时清理前一参与者待发送上下文，防止串号。

## 验证与上线边界

- 回归原三栏、26偏旁、183字图片、字源选择、现有游戏、词库范围、熊猫雨及本机记录，删除的两块文字不回来。
- 未登录/非创始人不能读后台或导出；普通研究码不能访问后台、伪造其他参与者、修改组别或服务端分数；初始化不存在抢占权限。
- 批量发码唯一、原码不落研究导出；跨天/跨设备同码关联一致；切号不会串数据；退出研究停止记录。
- 默认展示不算主动点击，重发事件不重复计数，重试不覆盖首次作答，未收录组合不判成错误汉字；后台与标签页隐藏时间排除。
- 用隔离测试研究验证汇总可从原始明细复算，空状态不显示假数据；测试记录与正式研究隔离且可识别。
- 分组/内容/测验版本冻结、缺失记录、实际延迟时间、导出完整性及CSV安全有有意义的测试。
- Sites迁移在本机验证后，使用同一Site与受众发布。上线时先保持研究为草稿，创始人绑定与研究配置完成才开始真实采集；不追补历史访问数。

## 明确留给实现者的选择

组件拆分、数据库索引、后台图表库、参数化查询和上传批大小等常规实现由实现者确定。具体班级人数、题目数量、研究开始日、保存截止日、分配方法由创始人在研究草稿里配置，不妨碍后台功能开发；没有配置完整时不能把演示数据或随意默认分组当成正式研究。

独立审查提出的三处缺口已在本草案补齐：首版有限题型、公开完整版带来的跨条件暴露、退出后历史记录的统计/导出规则。以上均标为实现者默认建议，用户仍可在审阅时调整。
